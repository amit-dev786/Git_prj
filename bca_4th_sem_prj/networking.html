TYPES OF NETWORK

PAN Network

The smallest, most intimate network, connecting devices like smartphones, laptops, and tablets within a 1–10 meter range.

LAN Network

Connects computers and devices within a small, specific area, such as a home, school, or single office building. Technologies include Ethernet and Wi-Fi.

MAN Network

Larger than a LAN but smaller than a WAN, this network connects multiple LANs within a city, town, or large campus, often using fiber optic cables.Used to input voice and audio signals.

WAN Network

Spans a large physical distance, connecting devices across countries or continents. The internet is the largest, most well-known example.

NETWORKING DEVICES

Router

Directs data traffic between different networks (e.g., home network to the internet).

Switch

Connects devices within a LAN (Local Area Network) and intelligently manages data forwarding to specific devices.

Hub

A basic, older device that broadcasts data to all connected devices.

Bridge

Connects two different network segments into one.

NETWORK TOPOLOGIES

Star Topology

All nodes connect to a central device (hub/switch). Highly scalable and easy to troubleshoot, but the central hub is a single point of failure.

Bus Topology

Devices connect to a single, central cable (backbone). Inexpensive and easy for small networks, but a failure in the backbone stops the entire network.

Ring Topology

Devices connect in a closed loop, with each device having two neighbors. Data travels in one direction. A break in the loop can disable the entire network.

Mesh Topology

Nodes are interconnected, with devices connecting to multiple other nodes. Highly reliable and fault-tolerant, but complex and expensive to implement.

NETWORK PROTOCOLS

TCP Protocol

TCP provides reliable connection oriented communication, ensuring accurate ordered data delivery using acknowledgments and retransmissions.

UDP Protocol

UDP provides fast connectionless communication without guaranteeing delivery or order, suitable for streaming and real time applications.

HTTP Protocol

HTTP transfers web pages between clients and servers using request response methods, enabling browsers to retrieve and display website content.

FTP Protocol

FTP transfers files between computers over networks, supporting uploading, downloading, and remote file management without built in encryption.
